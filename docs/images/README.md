The two gameplay captures (`horde-reticle-gameplay.png`,
`target-ring-gameplay.png`) show the author's earlier setup with Plater
nameplates, before Squanch-On drew its own. They illustrate component artwork,
not the complete new package or proof of an input transition. The target ring in
`target-ring-gameplay.png` and in `range-guide.svg` is the earlier dashed art;
the ring is now one solid line inside the selected plate. No private chat,
account exports or diagnostic overlays are included in these example images.

The diagrams are original project artwork. World of Warcraft, its characters,
game environments and game-provided artwork retain Blizzard Entertainment's
rights. Screenshot game content is not relicensed under the code's MIT license.
The repository does not distribute extracted Blizzard textures as addon assets.
